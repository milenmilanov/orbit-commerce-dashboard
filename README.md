# ORBIT — Commerce Analytics Dashboard

A fully interactive e-commerce administration dashboard built with **HTML, CSS and Vanilla JavaScript**.

ORBIT was created to demonstrate frontend application development beyond traditional landing pages — combining data visualization, state management, CRUD operations and persistent browser storage in a responsive dashboard interface.

## 🚀 Live Demo

🔗 [Launch ORBIT Dashboard](https://milenmilanov.github.io/orbit-commerce-dashboard/)

## ✨ Features

### 📊 Analytics Dashboard
- Interactive revenue chart
- 7 / 30 / 90 day data ranges
- Dynamic revenue metrics
- Order statistics
- Average order value
- Conversion rate
- Sales channel breakdown

### 📦 Product Management
- Add products
- Edit existing products
- Delete products
- Search products
- Filter by inventory level
- Low-stock indicators
- Persistent product data using LocalStorage

### 🧾 Order Management
- Search orders
- Filter orders by payment status
- Order status indicators
- Fulfillment tracking
- Responsive order tables

### 👥 Customer Management
- Customer overview
- Order history statistics
- Total customer spend
- Customer segmentation
- VIP / Returning / New customer states

### 🎨 Interface
- Responsive dashboard layout
- Desktop and mobile navigation
- Dark / Light mode
- Persistent theme preference
- Product management modal
- Adaptive tables and cards

## 🛠 Tech Stack

`HTML5` • `CSS3` • `JavaScript` • `Chart.js` • `LocalStorage`
